# Hallow Mud

A Halloween-themed LLM MUD set in Swede Hollow, Saint Paul, Minnesota.

## Setting
Set on All Hallows' Eve in the 1870s, in the Swedish immigrant neighborhood of Swede Hollow, Saint Paul. The veil between worlds is thin, and the ghosts of long-dead Swedish settlers have returned as ghosts, zombies, werewolves, and vampires.

## Theme
- Historical setting: Swede Hollow, Saint Paul - Swedish immigrant community from the 1800s
- Weapons and armor based on 19th century Swedish items (folkdräkt, lie/scythe, sledgehammer)
- Undead NPCs based on the area's historical inhabitants
- Dark, foggy Halloween atmosphere
